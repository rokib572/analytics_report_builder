# Reports

The report builder is the main place to explore trends, compare periods, and save recurring views for your team.

## Typical workflow

1. Open **Report Builder**.
2. Select the fields, groupings, or filters you need.
3. Review the preview panel to confirm the output matches the question you are answering.
4. Save the report if you expect to reuse it later.

## Useful report questions

| Question                                            | Suggested focus                                |
| --------------------------------------------------- | ---------------------------------------------- |
| Which locations are driving the most net sales?     | Group by location and compare total sales.     |
| Are discounts increasing over time?                 | Trend discounts over a date range.             |
| Which days had the highest order count?             | Group order count by day across the range.     |
| How much came from taxes, tips, or service charges? | Add the relevant monetary fields side by side. |

## Tips

- Start with a narrow date range when exploring a new question.
- Save reports with names your teammates will recognize later. Saved reports can be reopened, renamed, or removed from the report builder at any time.
- Use the export option on a report to download a CSV or PDF when you need to share results outside AperioBI.
- If a metric looks off, compare it against recent sync activity before assuming the data is wrong.

## Glossary

- **Gross sales** - total of item prices before any discounts or returns.
- **Net sales** - gross sales after discounts and returns, before tax, tips, and service charges.
- **Tender** - how a payment was made on an order (card, cash, and so on).
- **Fulfillment** - how an order was delivered to the customer (pickup, delivery, and so on).
